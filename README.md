# 供水管道检漏相关仪

双传感器互相关漏点定位系统。把老师傅"贴两根听音棒、戴耳机听哪边响"的经验做法，
做成基于 **GCC 加权互相关 + 管内水锤波速物理模型** 的软件定位，降低城区车流/水泵干扰下的
找漏时间和误挖率。

## 工作原理

两个传感器同时采集管道噪声，漏水声到两端存在时间差 τ：

```
        漏点
  A ●─────×──────────────● B
  │← dA →│←──── dB ─────→│
  │←──────── L ─────────→│

  τ = t_B − t_A          （B 相对 A 的到达时延）
  d_A = (L − c·τ) / 2
  d_B = (L + c·τ) / 2
```

- **声速 c**：Korteweg 薄壁弹性管理论公式
  `c = √[(K/ρ) / (1 + ψ·K·D/(E·e))]`，按管材弹性模量 E、泊松比 ν、
  管径 D、壁厚 e 与约束因子 ψ 计算。铸铁/钢/PE 三套材料预设。
- **时延 τ**：Welch 分段平均互谱 → GCC 加权（普通 / PHAT / SCOT）→ IFFT 相关曲线
  → 物理时延窗内寻峰 + 抛物线亚采样插值。
- **抗干扰**：零相位 Butterworth 带通（filtfilt，不引入附加相位差）先滤掉
  车辆低频轰鸣与水泵线谱；PHAT 白化把相关峰压尖。
- **可信度**：综合峰高、相干性 γ²、峰锐度、有效带宽与时延 CRB 距离不确定度打分，
  PE 管高频衰减快、峰钝，会自动下调评级并给出中文复测提示。

## 技术栈与结构

纯前端、零运行时第三方依赖（DSP 全部手写），数据存 IndexedDB，可离线运行。

```
src/
├─ dsp/
│  ├─ fft.ts            迭代 radix-2 FFT / 分数延迟
│  ├─ filters.ts        零相位 Butterworth 带通（RBJ 双线性 + filtfilt）
│  ├─ windows.ts        Hann 窗
│  ├─ materials.ts      声速物理模型 + 三种管材预设 + 频变衰减
│  ├─ random.ts         可复现随机数 / 高斯 / 粉噪
│  ├─ synthesizer.ts    双传感器噪声仿真（漏水声源+双路径+部分相干干扰）
│  ├─ sample-presets.ts 自编 9 个管网/漏水噪声样本（铸铁/钢/PE 各 3 工况）
│  ├─ correlator.ts     GCC 加权互相关 + 相干性 + 亚采样峰插 + 可信度
│  └─ analysis.ts       分析编排与距离解算（Worker/Node 共用）
├─ worker/correlation.worker.ts   相关分析 Web Worker（Transferable 零拷贝）
├─ audio/
│  ├─ recorder.worklet.ts         AudioWorklet 双通道 PCM 采集
│  └─ live-capture.ts             Web Audio 带通监听 + 采集服务
├─ pages/               管段录入 / 同步采集 / 相关分析 / 检漏记录 四页
├─ lib/                 IndexedDB 存储、响应式 store
└─ ui/                  Canvas 波形/频谱/相关曲线绘图
scripts/validate.ts     验收指标量化校验（Node 直跑，无浏览器依赖）
```

## 使用流程

1. **管段录入**：填管材、外径 D、壁厚 e、传感器间距 L、约束方式；页面实时算出
   理论声速并与该管材典型工程值对照（偏差 >5% 红色告警）。
2. **同步采集**：
   - *仿真模式*：从 9 个自编样本中选一个，一键合成 60s 双通道信号（含已知漏点真值，便于考核）；
   - *实时模式*：双通道声卡接两个传感器，`getUserMedia` + AudioWorklet 采集，
     Web Audio 链路实时带通，界面显示双路电平与进度。
3. **相关分析**：设滤波频带（可按管材一键推荐）、加权方法、FFT 窗长，
   计算在 Web Worker 内完成，界面不卡顿。输出漏点距 A/B 距离、相关曲线、双路频谱、
   可信度评级与施工提示，可归档为检漏记录。
4. **检漏记录**：状态流转（待开挖→已开挖→确认漏点/误判回填→回填修复），支持导出 CSV。

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 生产构建（Worker/Worklet 独立 chunk）
npm run preview    # 预览生产包
npm run validate   # 验收指标量化校验
```

## 验收结果（`npm run validate`）

| 指标 | 要求 | 实测 |
|---|---|---|
| 200m 铸铁管定位误差 | ≤ 管长 1%（2m） | **0.001%（≈0.00m）** |
| 理论声速 vs 典型工程值 | 偏差 ≤ 5% | **最大 1.19%** |
| 60s 双通道完整相关分析 | ≤ 1s | **最差 178ms（9 样本）** |

9 个样本全量结果：铸铁/钢管工况高可信度、误差近零；PE 钝峰工况自动降为中可信度，
强干扰长距离 PE 工况正确识别为低可信度并提示复测（该样本人为制造了约 5% 的大误差，
用于验证告警能力）。
